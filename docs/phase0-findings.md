## 2. 协议层教训（已固化进代码）

首轮评测 acc 仅 88%，但 11 个"错误"中 9 个概率向量是均匀分布——**不是判断错，是读出失败**：

1. 思考型模型首 token 可能不是字母（候选里出现 `<think>`）→ 必须 `enable_thinking=False`；
2. 服务端偶发返回空 top_logprobs（有 content 无概率）→ 自动重试（readout_retries=2）；
3. 全角字母/字母带标点 → 解析归一化；
4. 重试仍失败但 content 是字母 → 降级兜底并计 degraded（本次终跑 degraded=0）。

修复后 acc 88% → 94.6%，耗时 366s → 79s。**决策模型的"读出协议"本身就是工程护城河的一部分。**

## 3. 剩余 5 个真实错误的模式

| 用例 | 题型 | 模式 |
|---|---|---|
| cs-001/anger | score | 情绪等级边界（不满 vs 愤怒，模型 0.82 选愤怒） |
| mod-001/category | choice | "卖家是骗子"= 激烈差评 vs 人身攻击，边界歧义 |
| risk-004/risk | score | 高 vs 极高，相邻等级 |
| risk-006/risk | score | 最低还款≠高风险，模型偏谨慎（低 vs 中） |
| risk-007/risk | score | 高 vs 极高，相邻等级 |

**4/5 是 score 相邻等级错误，全部 score 错误的相邻等级准确率 = 100%。**
结论：有序评分是最难题型（等级边界天然模糊），choice/noul 已接近饱和。

## 4. 校准发现（重要）

- 原始 logits 已相当校准：ECE 0.047，平均置信度 0.993 vs 准确率 0.946（轻度过度自信）。
- 46 题校准集上 NLL 拟合温度 → T=3.25：NLL 改善但 **ECE 反而恶化**（0.047→0.064），
  置信度被压到 0.899（低于准确率，转为欠自信）。原因：小样本下少数高置信错误主导 NLL，单参数温度过拟合。
- **结论：温度缩放需要数千题级校准集（Phase 1 数据规模的理由）；小样本阶段应优先信原始 ECE，
  或改用 ECE 目标/正则化拟合（Phase 1 实验项）。**

## 5. Go/No-Go 结论（对照产品方案 §8）

零训练大模型基线已很强（acc 94.6% / ECE 0.047）→ **在准确率上继续卷大模型增量有限**。
Phase 1 重心按预案转向：

1. **端侧蒸馏**：把 ~95% 的中文决策能力蒸到 0.6B–4B、CPU 可跑、概率可信的小模型——这是真正的空隙；
2. **score 题型专项**：合成数据加大有序评分占比，软标签（多次采样投票分布）保留等级边界的不确定性；
3. **评测集扩建**：92 题只够方向性结论；扩到 2000+ 题（含分布外/对抗子集）才能支撑发布级校准声明；
4. 风控领域（85%）与边界歧义样本是训练数据优先注入方向。
